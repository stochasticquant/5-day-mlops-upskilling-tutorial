# 5-day-mlops-upskilling-tutorial

Two hands-on, five-day MLOps curricula. Each one is built around a single project you
carry from a raw script to a monitored, deployed, auto-retraining system.

| Week | Level | Project | Guide |
|---|---|---|---|
| 1 | Beginner to production-ready | California house-price service built from open-source parts: DVC, MLflow, FastAPI, Docker, Prometheus, Evidently, GitHub Actions | [docs/mlops-5-day-bootcamp.md](docs/mlops-5-day-bootcamp.md) |
| 2 | Intermediate to advanced | Real-time transaction fraud detection on Databricks: Delta Lake, Lakeflow pipelines, Feature Engineering in Unity Catalog, Models in UC, Model Serving, Lakehouse Monitoring, Asset Bundles | [docs/mlops-databricks-5-day-advanced.md](docs/mlops-databricks-5-day-advanced.md) |

Do week 1 first unless you already know experiment tracking, model registries, pipelines,
containers, and drift monitoring. Week 2 assumes all of that and maps every week-1 tool to
its Databricks equivalent.
